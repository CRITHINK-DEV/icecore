# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/CRITHINK-DEV/icecore/discussions).
- **Bugs:** [open an issue](https://github.com/CRITHINK-DEV/icecore/issues/new/choose) with the bug template. Run `dbt run-operation icecore.doctor` first and paste its output.
- **Security problems:** never in public; see [SECURITY.md](SECURITY.md).
- **Before you ask:** the [troubleshooting guide](docs/troubleshooting.md) covers the common setup problems.
